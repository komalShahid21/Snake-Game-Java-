# 🐍 Viper's Voyage (Snake Game)

## 📌 Description
A fully functional desktop version of the classic Snake Game. This project demonstrates strong understanding of Data Structures (Linked List/Queue) and Java GUI programming.

## 🛠️ Technologies Used
*   Java
*   Java Swing & AWT (for GUI and graphics)
*   Object-Oriented Programming (OOP)

## ✨ Key Features
*   **Custom Data Structure:** The snake's body is implemented using a Linked List (Queue logic) for efficient addition and removal of segments.
*   **Grid System:** A 24x24 grid system for precise movement and collision detection.
*   **Game Loop:** Uses Java's `Timer` class for smooth, continuous gameplay.
*   **Controls:** Arrow keys for movement, 'R' to restart after Game Over.
*   **Score Tracking:** Real-time score updates as the snake consumes food.

## 🚀 How to Run
1. Clone this repository.
2. Compile the Java file: `javac SnakeGame.java`
3. Run the game: `java game.SnakeGame` (ensure package structure is maintained or remove the package declaration if running standalone).
